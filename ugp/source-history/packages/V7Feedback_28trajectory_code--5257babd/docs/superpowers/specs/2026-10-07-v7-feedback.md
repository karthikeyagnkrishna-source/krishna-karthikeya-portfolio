# V7 leg, body and force feedback

User approved the architecture in chat and explicitly requested implementation and GPU training. This document records that approved design; no additional approval is needed for its implementation.

## Model

Preserve the completed V7/V7-F and V7Legs/V7B run as read-only parents. Reuse the exact 28 training trajectories and four strict unseen trajectories. Keep short (+0.1 s; 0.5 s history) and long (+0.2 to +1.0 s; 4 s history) experts separate.

The frozen foundation runs once. The frozen completed hybrid provides the seed leg/body state and V7-F supplies seed force. A trainable copy of the hybrid starts from its joint-best checkpoint. Its leg and body projections, transformers and output heads are reused. Zero-initialized adapters introduce previous leg/body state. A new force refiner consumes original x, learned leg/body tokens, current joint/body predictions, geometry, contact, previous force, leg identity and horizon. It projects to 256 values, mixes four legs plus a body token through two 8-head transformer layers, then applies two transformer layers across horizons per leg. A zero-initialized 256->128->3 output predicts force correction.

Three rounds share the same leg/body/force weights. Each round updates legs, recomputes FK/Jacobian, updates body, then updates force. Leg/body candidates remain anchored to original V7 predictions; force candidates remain anchored to seed V7-F. Actual updates blend candidates with previous estimates using learned gates, initialized at 0.25 and capped at 0.5. Force correction is bounded to two training standard deviations per axis. The frozen seed and zero new adapters guarantee seed-equivalent predictions before new training in evaluation mode. A candidate computed in one round is never blindly added again to the previous round.

Future labels never enter model.forward. Future recorded controls remain known exogenous inputs as in the source protocol. Body outputs remain acc/gyro/linear velocity/angular velocity, 12 channels, not world position/orientation. Contact remains a frozen prediction; observed contact is used only for training masks.

## Data and losses

Load the completed parent per-trajectory caches rather than rerun vision. Attach actual force at stored target timestamps from the original physics cache, and verify against saved gtF. Retain the parent's train/validation masks and input normalization; fit a separate true-force correction scale using optimization windows only. Store hashes of source caches, parent weights, original foundation, scalers and implementation.

Leg/body/FK/stance losses reuse the existing objective. Correction anchor terms are measured relative to the frozen hybrid seed. Force loss: normalized vector SmoothL1 beta=.35 + .25 log-magnitude SmoothL1 beta=.20 + .10 nonzero-actual-force direction error + .10 matching horizon-difference SmoothL1. Direction normalization uses a 1 N floor to prevent a zero predicted vector causing huge gradients. Short branch omits the horizon-difference term. Full objective weights the three rounds .2/.3/.5, with the existing .1 stance and .01 correction anchors. Selection uses supervised errors and excludes anchors/stance.

Stage A trains only the force refiner using seed leg/body tokens for one force update. Stage B initializes from A and tunes the trainable hybrid, adapters, gates and refiner through three rounds, with all supervised losses active. The frozen seed/foundation never receive gradients. Defaults reuse AdamW, 3e-4 new force stage, 5e-5 joint stage, weight decay 1e-4, clipping 1.0, validation patience 5 and .1% relative improvement; initial limits 30 force epochs and 15 joint epochs match the parent. Batch sizes 16 short/8 long, adjusted only for measured memory requirements. Checkpoints restore optimizer/RNG/order/cursor/best/patience and reject changed provenance.
