# V8 contact-map experiments

V8-A through V8-F extend the V7 research line with persistent contact memory, touchdown prediction, a local contact-response field, counterfactual terrain comparisons, a micro-foothold planner, and bounded adaptation. This directory contains a standalone **earlier Colab notebook** with outputs removed and a later **saved RTX aggregate export**. The notebook had one recorded error before sanitization, so it is an experiment record rather than a claimed end-to-end clean run. The RTX V8 cells also appear in the V7/V7-F research notebook.

The aggregate results have different tasks and denominators. V8-A retrieved nearby causal memory for 10,302/10,422 contact queries in the audited familiar cases; a hit does not prove long-lead coverage. V8-B predicted contact for every one of 512 diagnostic rows, giving trivial perfect recall rather than useful discrimination. V8-C's force-vector error was about 127.65 N and used actual future foot XY, which is an oracle input. V8-D's matched-pair summary records 1,859 pairs and 36.7% force-magnitude ranking accuracy. V8-E was offline shadow planning, and V8-F was causal replay/adaptation, neither closed-loop robot execution.

See `results/` for the original saved aggregate CSVs. Their case selection and target definitions are not interchangeable with the strict V7-F holdout. Reproduction requires the private synchronized recordings, pretrained V7 features, calibration, and the specific experimental notebook environment. No deployment or physical terrain reconstruction claim follows from these exports.
